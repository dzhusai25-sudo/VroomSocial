# 🚗 VroomSocial — Сообщество автолюбителей

[![React](https://img.shields.io/badge/React-18.2-61DAFB?logo=react)](https://reactjs.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.0-3178C6?logo=typescript)](https://www.typescriptlang.org/)

**VroomSocial** — это веб-платформа, где автомобильные энтузиасты делятся своими историями, обзорами, советами по ремонту и впечатлениями от тест-драйвов. Здесь каждый может создать свой пост, загрузить фото, оставить комментарий, сохранить понравившуюся статью в избранное и найти единомышленников по марке авто или типу увлечения.

🔗 **Демо:** [_VroomSocial на GitHub Pages_](https://dzhusai25-sudo.github.io/VroomSocial/)
📦 **Репозиторий:** [/VroomSocial](https://github.com/dzhusai25-sudo/VroomSocial)

---

## ✨ Возможности

- 🔐 **Аутентификация** — регистрация, вход, заполнение профиля
- 💬 **Создание впечатлений** — указание города, выбор а/м, загрузка фото и заполнение текста
- ❤️ **Лайки** — возможность оценить чужие публикации
- 🔍 **Фильтрация** — по марке и модели автомобиля
- 🚘 **Каталог автомобилей** — марки и модели (интеграция с открытым API)
- 📱 **Адаптивный дизайн** — удобная работа на мобильных устройствах и планшетах

---

## 🛠 Стек технологий

### Frontend
- **React 18** + **TypeScript**
- **React Router v6** — маршрутизация
- **Material‑UI (MUI)** — компоненты и стилизация
- **React Query** — кэширование и работа с серверными данными
- **Vite** — сборка

### Backend as a Service
- **Supabase** — аутентификация, база данных (PostgreSQL), storage для фото

### Инструменты

- **ESLint** + **Prettier** — качество кода
- **Jest** + **React Testing Library** — тестирование
- **GitHub Actions** — CI/CD
- **GitHub Pages** — деплой фронтенда

## 📋 Обязательные требования к проекту

- **поддержка пользовательских сессий / сохранение пользовательских данных**
- **использование внешнего API**
- **минимум 3 разных роута**
- **использование параметризированных роутов**
- **настроены линтеры, тесты и автодеплой через CI/CD**
- **возможность проверить приложение без локального запуска**
- **оформленный репозиторий и README**
- **покрытие кода тестами от 50%**

## ✅ Дополнительные требования

- **аутентификация пользователя**
- **отзывчивый дизайн**
- **совместная работа пользователей**
