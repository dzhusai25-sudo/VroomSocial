# 🚗 VroomSocial — Сообщество автолюбителей

[![React](https://img.shields.io/badge/React-18.2-61DAFB?logo=react)](https://reactjs.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.0-3178C6?logo=typescript)](https://www.typescriptlang.org/)

**VroomSocial** — это веб-платформа, где автомобильные энтузиасты делятся своими историями, обзорами, советами по ремонту и впечатлениями от тест-драйвов. Здесь каждый может создать свой пост, загрузить фото, оставить комментарий, сохранить понравившуюся статью в избранное и найти единомышленников по марке авто или типу увлечения.

🔗 **Демо:** *скоро будет доступно*  
📦 **Репозиторий:** https://github.com/dzhusai25-sudo/VroomSocial

---

## ✨ Возможности

- 🔐 **Аутентификация** — регистрация, вход, редактирование профиля
- 📝 **Посты** — создание, редактирование, удаление статей
- 💬 **Комментарии** — обсуждение постов, возможность редактировать/удалять свои комментарии
- ❤️ **Лайки и избранное** — оценка публикаций и сохранение в личный список
- 🔍 **Поиск и фильтрация** — поиск по заголовку, фильтрация по марке автомобиля и тегам
- 🚘 **Каталог автомобилей** — информация о марках и моделях (интеграция с открытым API)
- 📱 **Адаптивный дизайн** — удобная работа на мобильных устройствах и планшетах

## 🛠 Стек технологий

- **React 18** + **TypeScript** — компонентный подход с типизацией
- **React Router v6** — маршрутизация
- **React Query (TanStack Query)** — управление серверным состоянием, кэширование
- **TBD** — глобальное состояние (тема, пользователь, избранное)
- **TBD** — стилизация
- **React Hook Form** — работа с формами
- **Vite** — быстрая сборка проекта
- **Supabase** — BaaS (аутентификация, база данных PostgreSQL, realtime)
- **Supabase Storage** — хранение изображений
